# Aplicação de Portfólio em Flask

Esta é uma aplicação web baseada em Flask que mostra o que foi densenvolivido na aula de Framework para Desenvolvimento Web.


## Funcionalidades

- Exibir os dias das aulas e o que aconteceu.
- Direcionar para os projetos caso tenha tido na aula.

## Instalação

1. Clone o repositório:
    ```sh
    git clone https://github.com/kauan345developer/frameworksWeb.git
    cd portfolio
    ```

2. Crie um ambiente virtual e ative-o:
    ```sh
    python -m venv venv
    source venv/bin/activate  # No Windows use `venv\Scripts\activate`
    ```

3. Instale as dependências:
    ```sh
    pip install -r requirements.txt
    ```

## Executando a Aplicação
```sh	
python app.py
```


## Estrutura do Projeto

- `app.py`: Arquivo principal da aplicação contendo rotas e lógica.
- `templates/`: Diretório contendo templates HTML.
- `static/`: Diretório contendo arquivos estáticos (CSS, JS, imagens).
